# Bryan Focht — Resume

Two self-contained, static HTML pages, served with [GitHub Pages](https://bfocht.github.io/) — no build step, no dependencies, nothing to install.

| File | What it is |
| --- | --- |
| `index.html` | Interactive resume: a force-directed knowledge graph of positions, organizations, skills and credentials. Needs a current browser (canvas, `requestAnimationFrame`). |
| `resume.html` | Plain no-JavaScript fallback and printable version — what older browsers and screen readers land on, and what `index.html` redirects to if it can't run. |

Both are generated output, not hand-edited. They're built from the same data
